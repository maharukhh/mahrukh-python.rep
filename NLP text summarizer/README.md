NLP Text Summarizer

A simple Natural Language Processing (NLP) project that summarizes a long paragraph into a shorter version by selecting the most important sentences.

Features
- Accepts user input text
- Splits text into sentences
- Calculates word frequencies
- Scores each sentence based on important words
- Generates a short summary automatically

Technologies Used
- Python
- Collections (Counter)
- Regular Expressions (re)

How It Works
1. User enters a paragraph.
2. The program splits the text into sentences.
3. Word frequencies are calculated.
4. Each sentence receives a score based on the frequency of its words.
5. The top-scoring sentences are selected as the summary.
6. The summary is displayed on the screen.
