Mini Rectangle Game 
A simple rectangle jumping game made using Python and Pygame.
The player controls a green rectangle that jumps over moving obstacles.
If the rectangle collides with an obstacle, the game ends.

Features
Simple beginner-friendly Python code
Jump functionality
Moving obstacle animation
Collision detection
Easy to understand game logic

Install Pygame using:

```bash 
pip install pygame
```

## How to Run

To run the program:

```bash
python mini_rectangle_game.py
```

Controls
Spacebar → Jump

Game Rules
Avoid the black obstacle.
The game ends if the player touches the obstacle.
