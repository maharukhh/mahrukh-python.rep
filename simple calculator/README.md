 Simple Calculator

This is a basic calculator program written in Python. It allows users to perform simple arithmetic operations such as addition, subtraction, multiplication, and division. The user enters two numbers and an operator, and the program displays the result.

 Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Easy-to-use command-line interface


 How It Works
1. The user enters the first number.
2. The user enters an operator (+, -, *, /).
3. The user enters the second number.
4. The program performs the selected operation.
5. The result is displayed on the screen.
