# AI-Based Student Result Prediction System

## Project Overview
This project is a simple AI and Machine Learning based system developed in Python. The system predicts whether a student will Pass or Fail based on:

- Study Hours
- Attendance Percentage
- Previous Marks

The project uses the Decision Tree Machine Learning algorithm for prediction.

---

# Features

- Simple and beginner-friendly project
- Uses Machine Learning
- Predicts student performance
- Takes user input
- Displays prediction result
- Uses CSV dataset

---

# Technologies Used

- Python
- Pandas
- Scikit-Learn
- Decision Tree Classifier
- VS Code
