This project is a simple Spam Email Detector made using Python.
The program checks whether an email message is spam or not by searching for common spam keywords such as:

free
win
money
offer

If these words are found in the email text, the program labels the email as SPAM EMAIL. Otherwise, it shows NOT SPAM.

Features
Simple and beginner-friendly Python code
Detects spam using keywords
Uses user input
Easy to run in VS Code or terminal

How the Program Works
User enters an email message.
Program converts the text into lowercase.
Program checks for spam keywords.
If spam words are found:
Output → SPAM EMAIL
Otherwise:
Output → NOT SPAM
