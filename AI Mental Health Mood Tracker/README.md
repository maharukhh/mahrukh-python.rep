 AI Mental Health Mood Tracker

A simple Python mood tracker that lets users record their daily mood, stress level, sleep hours, and short notes. It uses basic sentiment analysis to give simple wellness suggestions.

 Features

- Add daily mood entries
- Save data in a JSON file
- Analyze notes as Positive, Negative, or Neutral
- Give basic AI-style suggestions
- Show mood summary
- Calculate most common mood and average stress level

 Technologies Used

- Python
- JSON
- datetime
- collections
