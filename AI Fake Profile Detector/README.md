 Fake Profile Detector

It is a simple Python-based project that identifies whether a social media profile is likely to be real or fake using basic profile information. The system analyzes factors such as followers, following count, number of posts, and account age to make a prediction.


 Features
- Detects potentially fake profiles
- Simple and easy-to-use interface
- Rule-based prediction system


 How It Works
The program asks the user to enter:
- Number of followers
- Number of following
- Number of posts
- Account age (in months)
Based on predefined rules, the program calculates a score and predicts whether the profile is likely fake or real.
