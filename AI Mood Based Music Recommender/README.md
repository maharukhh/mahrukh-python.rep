 AI Mood-Based Music Recommender

A simple Python project that recommends Hindi and Urdu songs based on the user's mood.

 Features

- Takes mood input from the user
- Recommends a random song
- Supports Hindi and Urdu songs
- Uses a dictionary to store songs
- Uses Python `random` module

 Moods Available

- happy
- sad
- angry
- relaxed
- romantic
