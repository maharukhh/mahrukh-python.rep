Object Detection System

A simple Object Detection System built using Python, OpenCV, and YOLOv8.  
This project detects objects in real time using a webcam.

Features
- Real-time object detection
- Webcam support
- YOLOv8 AI model
- Beginner-friendly project

Technologies Used
- Python
- OpenCV
- YOLOv8
